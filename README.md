# School Manager Pro — لوحة القيادة الذكية لمدير المدرسة الابتدائية

تطبيق ويب عربي (RTL) لإدارة مدرسة ابتدائية واحدة، يعمل في المتصفح ويحفظ البيانات محليًا على الجهاز (IndexedDB) دون خادم.

## التشغيل

المتطلبات: Node.js 18 أو أحدث.

```bash
npm install
npm run dev        # خادم التطوير: http://localhost:5173
npm test           # تشغيل الاختبارات الآلية
npm run build      # بناء نسخة الإنتاج في مجلد dist/
npm run preview    # معاينة نسخة الإنتاج
```

نسخة `dist/` ملفات ثابتة يمكن تقديمها من أي خادم ملفات ثابتة (يستعمل التطبيق `HashRouter` و`base: './'`).
يتطلب IndexedDB سياقًا آمنًا: افتحه عبر `http://localhost` أو `https`، وليس بفتح `index.html` مباشرة من القرص.

عند أول تشغيل، يُطلب إنشاء كلمة مرور المدير، ثم تبدأ قاعدة البيانات فارغة: لا توجد أي بيانات تجريبية.

## التخزين والأمان (بصراحة)

- البيانات المنظمة في IndexedDB عبر Dexie.js، والملفات المرفقة كـ Blob في IndexedDB، والإعدادات البسيطة في localStorage.
- كل عملية تُحفظ فورًا، وتبقى البيانات بعد إغلاق المتصفح. يطلب التطبيق من المتصفح تخزينًا دائمًا (`navigator.storage.persist`).
- **لا مزامنة بين الأجهزة.** لنقل البيانات: صدّر نسخة احتياطية JSON ثم استوردها على الجهاز الآخر.
- النسخة الاحتياطية JSON تشمل كل الجداول والإعدادات والشعار، والملفات المرفقة بشكل اختياري (base64).
- قبل الاستيراد يُتحقق من بنية الملف، ويُطلب تأكيد الاستبدال. تتم الاستعادة في معاملة واحدة: إذا فشلت تبقى البيانات الحالية كما هي.
- كلمة المرور محفوظة كتجزئة PBKDF2-SHA256 (210000 تكرار، ملح عشوائي)، ولا تُحفظ كنص.
- **البيانات نفسها غير مشفّرة.** شاشة الدخول تحمي الواجهة فقط، ويمكن لمن يصل إلى حساب المتصفح على الجهاز مع أدوات المطوّر قراءة البيانات. ملفات النسخ الاحتياطية غير مشفّرة أيضًا.
- لا يمكن استرجاع كلمة مرور منسية. الحل: مسح بيانات الموقع من المتصفح ثم استعادة نسخة احتياطية.

## حدود معروفة

- **PDF**: يتم التصدير عبر نافذة الطباعة في المتصفح (اختيار "حفظ بصيغة PDF")، لأن هذه الطريقة تعرض الحروف العربية متصلة وصحيحة. لا يوجد توليد PDF مباشر داخل التطبيق.
- **استيراد Excel** متاح للتلاميذ فقط (مع نموذج قابل للتحميل). بقية الوحدات تُصدَّر إلى Excel ولا تُستورد منه.
- **ملفات Word** تُحمَّل ولا تُعرض داخل المتصفح. ملفات PDF والصور تُفتح مباشرة.
- **الإشعارات** تظهر داخل التطبيق فقط (مركز الإشعارات)، ولا تُرسَل إشعارات نظام أو رسائل SMS.
- **محاور التقييم** الافتراضية مجرد أمثلة قابلة للتعديل، ولا تمثل مرجعًا رسميًا.
- سعة التخزين يحدّدها المتصفح، وتظهر المساحة المستعملة في الإعدادات.

## الاختبارات

`npm test` يشغّل `src/test/data.test.ts` (18 اختبارًا على IndexedDB محاكاة عبر fake-indexeddb):

- الإضافة والتعديل والحذف، مع حذف السجلات التابعة أو فك ارتباطها.
- تعديل تسجيل حضور سابق مع حفظ تاريخ التعديل في السجل.
- بقاء البيانات بعد إغلاق قاعدة البيانات وإعادة فتحها.
- تصدير نسخة كاملة (مع ملف مرفق) ← مسح ← استعادة ← التحقق من البيانات والإعدادات.
- رفض نسخة غير صالحة دون المساس بالبيانات الحالية، وتنقية الإعدادات المستوردة.
- تجزئة كلمة المرور والتحقق منها ورفض كلمات المرور الضعيفة.
- حساب المعدلات المرجّحة، وإحصائيات الامتحانات، والمهام المتأخرة، والغيابات المتكررة.
- التحقق من صحة المدخلات (إلزامي، بريد، هاتف، مجال رقمي).

الواجهة نفسها مختبرة يدويًا في المتصفح، ولا توجد اختبارات آلية للمكوّنات.
